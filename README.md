## Convenção de classes CSS

Usamos BEM: o bloco tem um nome próprio (`.card`), seus elementos usam `__` (`.card__title`) e suas variações usam `--` (`.btn--primary`). Classes reutilizáveis, como `.container`, podem ser blocos independentes.
